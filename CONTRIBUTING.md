# Contributing to Awesome LLM Security Tools

Thank you for considering contributing to this project!   🎉

## ✅ How You Can Contribute

### 1. Add New Tools / Papers / Datasets
- Find the correct section in `README.md`
- Add a bullet with:
  - **Name** (linked to GitHub)
  - One‑line description
  - Optional: star count, last updated (use `YYYY‑MM‑DD`)
- Submit a PR with your addition.

### 2. Update Existing Entries
- Fix links, descriptions, star count, or update timestamps.
- Inaccurate info? Add a note (e.g., _"last checked 2025‑07‑06"_).

### 3. Report Issues
- Broken links? Misclassified entries? Missing context?
- Use GitHub Issues with a clear title and description.

### 4. Community Guidelines
- Keep a friendly, inclusive tone.
- Use respectful language and cite sources where possible.
- Avoid advocating for illicit use.

---

## 🧭 Maintainer Guide

- Review incoming PRs and issue triage weekly.
- Run `npm run format` (if using Prettier) to keep formatting consistent.
- Update aggregated stats (stars, updates) quarterly.
